# 腦友記 · 每日動腦筋

為長者（包括輕度至中度腦退化症朋友）而設的記憶與思考小練習網站。全部用**大字、高對比、大按鈕、廣東話語音提示**，**唔計時、唔計分、做錯唔會扣分**，一次做一個練習就夠。

- 網址：<https://tyhcch1234.github.io/brain-training-seniors/>
- 純靜態網頁：無需登入、無廣告、無追蹤、不相依任何外部 CDN，離線亦可開啟（已載入過的頁面）。

## 六個練習

| 練習 | 訓練方向 | 玩法 |
| --- | --- | --- |
| 🃏 記憶配對 | 視覺記憶、專注 | 翻開六張卡，找出三對相同圖案 |
| 🧺 記三樣嘢 | 短期記憶 | 先看三樣物件，之後在六樣之中認返出來 |
| 🔢 數字次序 | 專注、排序 | 由 1 開始順序按下六個數字 |
| ☂️ 生活常識 | 判斷力、安全意識 | 日常情境三選一（帶雨傘、過馬路、陌生來電等） |
| ⭐ 找相同 | 視覺辨識 | 在六個圖形中找出與示範完全相同的一個 |
| 🍎 物件分類 | 語意記憶、分類 | 把物件分入「生果」或「衣物」 |

另有 **💬 傾偈卡**：10 條懷舊／生活話題，方便家人陪長者傾談（呢部分唔算練習、唔計分）。

## 設計考慮

- **字體**：預設 20px 起，可一鍵切換「大字 / 特大 / 超大字」（1×、1.15×、1.3×）。
- **按鈕**：主要按鈕高度不少於 3.5rem（約 70px），圖卡接近 100px，減少手震誤觸。
- **零壓力**：沒有倒數計時、沒有分數、沒有「錯誤」字眼；做錯只會溫和提示「唔緊要，再試一次」。
- **提示與引導**：答錯時會用光框標示正確位置（errorless learning 取向），避免長者反覆受挫。
- **語音**：使用瀏覽器內建語音（zh-HK 優先），每一題都可按「🔊 再讀一次」。
- **一致性**：每個練習都是同一版面、同一操作方式（點按），不需要拖放或滑動。
- **完成即鼓勵**：每完成一個練習有鼓勵畫面和「今日已做 N 個」記錄（只存在自己的瀏覽器）。
- **可及性**：清楚焦點框、`aria-live` 回饋、`prefers-reduced-motion` 支援、可放大縮放（未鎖定 viewport）。

## 檔案結構

```
index.html        版面（首頁 / 練習 / 完成三個畫面）
css/style.css     樣式（大字、高對比、列印以外的顯示設定）
js/app.js         共用工具、首頁、畫面切換、語音、本機記錄
js/games.js       六個練習的邏輯
manifest.json     PWA 設定（可「加到主畫面」）
favicon.svg       圖示
```

## 本機預覽

直接用瀏覽器打開 `index.html` 即可；或起一個本機伺服器：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 加到手機／平板主畫面

- **iPhone / iPad（Safari）**：分享 → 「加入主畫面」
- **Android（Chrome）**：右上選單 → 「安裝應用程式」或「加到主畫面」

加入後可全螢幕開啟，像一個 App。

## 給家人／照顧者的使用建議

1. 每次 1–2 個練習（約 5–10 分鐘）就夠，攰就停。
2. 陪住一齊做、慢慢讀出題目，比獨自完成更有意義。
3. 做錯唔需要糾正到底，可以講「我哋再睇一次」。
4. 如果長者煩躁或抗拒，就換做「傾偈卡」，或改天再玩。
5. 記錄只用來给予鼓勵，不用來比較或考核。

> 本網站是日常動腦筋的小遊戲，屬認知刺激／懷舊活動性質，**不能代替醫生診斷、藥物治療或正規認知訓練**。如有記憶或情緒明顯變化，請諮詢醫生。
